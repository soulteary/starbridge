# Starbridge 0.1.0 · 星桥首版

在 macOS 上通过 CLI 或本地 stdio MCP 管理 Parallels Desktop，并用结构化 JSON 观察、操作和验证 Windows 应用。

## 本版能力

- **VM 管理与回收**：列表、详情、启停、挂起、恢复、克隆和快照管理；支持停止保留、恢复快照、删除三种回收方式。破坏性操作需要明确确认，带策略文件的回收使用 UUID 定位目标。
- **Windows 查询与输入**：查询进程、窗口位置和 UIA 控件信息；按窗口身份执行 UIA 语义操作、聚焦、调整大小、鼠标和按键操作，支持中文、emoji 等 Unicode 文本输入。
- **截图与视觉闭环**：显式选择 PrintWindow 或 Windows Graphics Capture；`ui.observe → ui.click → 新观察` 校验窗口身份、截图年龄、几何和 DPI。MCP 直接返回 PNG 图片。候选识别由客户端视觉模型、OCR 或使用者完成，Starbridge 不内置识别模型。
- **开发调试流程**：具名应用任务与有界日志、文件上传/下载和增量同步、完整 helper 安装/回退、条件等待与断言、带检查点的工作流，以及带哈希清单的证据导出。
- **CLI / MCP 控制**：离线预演、参数与执行预算、独立 VM/guest 写授权、按 VM 与动作的访问策略、嵌套授权检查和宿主 workspace 限制。

## 使用边界

需要支持 CLI 的 Parallels Desktop、Windows Parallels Tools，以及配套 Windows PowerShell 5.1 helper。窗口、UIA、截图和输入依赖已登录、可访问的交互桌面及应用权限；UIA 内容取决于应用提供程序。WGC 需要 Windows 10 build 18362 或更高版本、相应 API 与硬件 D3D11 支持，不能保证任意应用都能捕获。

点击或输入的 `dispatched` 不表示业务成功，应检查新观察或明确的后置条件。超时/取消不能证明写操作未发生；结果为 `unknown` 时先核实实际状态，再决定是否重试。导出的截图、控件文字和日志可能包含敏感内容。

本次发布**未运行真实 Parallels / Windows 桌面端到端验收**。Go、协议和 Windows 合成测试不替代真实应用兼容性验证；具体环境请按[验收指南](https://github.com/soulteary/starbridge/blob/v0.1.0/docs/ACCEPTANCE.md)单独验证。

项目采用 **GPL-3.0-only**；第三方许可随包提供。安装包尚未进行 **Apple Developer ID 签名或公证**，SHA-256 校验和不等同于平台签名。
